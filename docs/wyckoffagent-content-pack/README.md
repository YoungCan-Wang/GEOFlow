# WyckoffAgent GEOFlow Content Pack

This pack turns GEOFlow into a content engine for WyckoffAgent discovery.

Target entity: **WyckoffAgent**  
Primary search intent: **trading agent**, **AI trading agent**, **Wyckoff trading agent**, **stock screener agent**

## Files

- `knowledge-base.md` — factual product and compliance source material for GEOFlow RAG.
- `keywords.txt` — import into a GEOFlow keyword library.
- `titles.txt` — import into a GEOFlow title library.
- `prompt-template.md` — use as the article generation prompt template.
- `review-checklist.md` — use before approving or publishing finance-related articles.

## Recommended GEOFlow Setup

1. Create a knowledge base named `WyckoffAgent Canonical Facts`.
2. Upload or paste `knowledge-base.md`.
3. Create a keyword library named `WyckoffAgent Trading Agent Keywords`.
4. Import `keywords.txt`.
5. Create a title library named `WyckoffAgent GEO Titles`.
6. Import `titles.txt`.
7. Create an AI prompt named `WyckoffAgent Compliance-Safe GEO Article`.
8. Paste `prompt-template.md`.
9. Generate drafts first, then review with `review-checklist.md`.

## Publishing Cadence

Publish 2-3 pages per week at first. Start with exact-match pages:

- Wyckoff trading agent
- AI trading agent
- stock screener agent
- open-source trading agent

Then expand into educational long-tail content around Wyckoff phases, spring detection, volume-price analysis, MCP tools, and CLI workflows.
