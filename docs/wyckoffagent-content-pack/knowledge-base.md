## One-Sentence Definition

WyckoffAgent is an open-source Wyckoff trading agent and AI stock screener for research, education, volume-price analysis, market-structure screening, and human-in-the-loop portfolio review.

## Product Positioning

WyckoffAgent should be described as a trading analysis assistant, not as an automated profit system. It helps users structure market research with Wyckoff volume-price logic, stock screening, CLI commands, web interfaces, local dashboards, scheduled workflows, and MCP-compatible tools.

## Core Capabilities

- Natural-language AI agent workflow for market analysis.
- Wyckoff volume-price structure review.
- A-share stock screening with a five-layer funnel.
- Portfolio diagnosis and risk-zone review.
- Recommendation tracking and signal confirmation.
- CLI and local dashboard workflows.
- Local SQLite-backed usage.
- GitHub Actions automation.
- MCP server exposing Wyckoff analysis tools to compatible clients.
- Web app for interactive research.

## What WyckoffAgent Can Help Review

- Accumulation context.
- Distribution risk.
- Spring and test patterns.
- Upthrust and failed breakout behavior.
- Sign of Strength and Last Point of Support context.
- Volume expansion or supply pressure.
- Position-level risk and invalidation zones.

## What WyckoffAgent Does Not Claim

- It does not guarantee returns.
- It does not predict every market move.
- It does not replace financial judgment.
- It does not provide personalized investment advice.
- It does not determine suitability for any individual.
- It does not remove execution, liquidity, slippage, tax, or portfolio risk.
